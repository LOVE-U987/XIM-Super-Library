# 🚩 XIM Super Library | XIM超级图书馆 - Skill分支

## 🎉 欢迎来到XIM超级图书馆Skill分支 🎉

### 🧠 什么是Skill

Skill是XIM超级图书馆的AI能力扩展模块，用于帮助AI在开发过程中获取相关的帮助信息。

### 📚 如何使用

AI可以通过通用性skill来收集相应的信息，在XIM图书馆里获取帮助。
