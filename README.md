# 🚩 XIM Super Library | XIM超级图书馆 - NeoForge分支

## 🎉 欢迎来到XIM超级图书馆 🎉

### 🐦‍⬛ 将精力放在需要的地方

因为部分开发环境的构建需要外国的相关网址加速，在这里你可以直接下载已被构建的相关的开发环境，可以极大的节省你的时间。

### 🎇 如何使用

1. 在文件列表中找到你需要的NeoForge版本构建文件（.7z格式）
2. 点击下载并解压到本地
3. 使用IDE打开即可开始开发

### 🎐 当前分支说明

- 当前分支为 `NeoForge` 分支，该分支为 NeoForge 环境的构建分支
- 该分支下的文件为 NeoForge 各版本环境的构建文件，你可以选择你需要的版本下载使用

### 🧩 关于Skill

XIM超级图书馆还提供Skill模块，用于帮助AI获取开发帮助信息。

- 切换到 `skill` 分支查看AI技能文件和规则文档
- 贡献Skill请遵守通用性规则、命名规则与摆放规则
