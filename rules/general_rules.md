# 📋 通用性规则

## 1. 目的

通用性规则确保所有Skill都遵循统一的标准，使得AI能够正确高效地进行编码与查阅。

## 2. 基本原则

### 2.1 准确性
- 所有Skill提供的信息必须准确无误
- 对于不确定的内容，必须明确标注
- 版本信息必须与实际内容对应

### 2.2 完整性
- Skill应覆盖所描述主题的核心内容
- 提供必要的代码示例和使用说明
- 包含相关的依赖和配置信息

### 2.3 易用性
- 使用清晰简洁的语言描述
- 提供结构化的信息便于AI解析
- 包含索引和关键词便于检索

### 2.4 兼容性
- 保持与主流AI助手的兼容性
- 使用标准的格式和标记
- 避免使用特定平台的专有语法

## 3. 格式规范

### 3.1 文档结构
- 必须包含标题和简介
- 使用清晰的层级结构
- 代码块必须标注语言类型

### 3.2 元数据
- 必须包含版本号
- 必须包含更新日期
- 必须包含作者信息

## 4. 更新与维护

- 定期检查并更新过时的信息
- 响应社区反馈进行改进
- 保持与最新技术同步
