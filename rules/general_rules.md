# 通用性规则

## 1. 目的

统一所有 Skill 的编写标准，使 AI 能够正确高效地编码与查阅。

## 2. 基本原则

### 2.1 准确性
- 所有 Skill 提供的信息必须准确无误
- 不确定的内容必须明确标注
- 版本信息必须与实际内容对应

### 2.2 完整性
- Skill 覆盖所描述主题的核心内容
- 提供必要的代码示例和使用说明
- 包含相关的依赖和配置信息

### 2.3 易用性
- 使用清晰简洁的语言
- 提供结构化的信息便于 AI 解析
- 包含索引和关键词便于检索

### 2.4 兼容性
- 保持与主流 AI 助手的兼容性
- 使用标准的格式和标记
- 避免特定平台的专有语法

## 3. 格式规范

### 3.1 文件格式
- Skill 文件使用 Markdown 格式（.md），UTF-8 编码
- 文件名采用小写字母和连字符组合

### 3.2 文档结构
- 必须包含标题和简介
- 使用清晰的层级结构
- 代码块必须标注语言类型
- 推荐结构：
  1. 元信息（名称、版本、作者、日期等）
  2. 简介
  3. 使用方法
  4. 参数说明（如有）
  5. 示例代码
  6. 相关资源
  7. 注意事项

### 3.3 元数据
- frontmatter 包含 `name`、`description`、`tags`
- 必须包含版本号和更新日期
- 推荐包含作者和分类信息

## 4. 更新与维护

- 定期检查并更新过时信息
- 响应社区反馈进行改进
- 保持与最新技术同步
