# 命名规则

## 1. 文件命名

- Skill 文件使用 `.md` 扩展名，UTF-8 编码
- 采用小写字母、数字和连字符组合
- 命名格式：`技术栈-版本号-功能描述.md`
- 版本号使用点分隔：`neoforge-1.21.1-config-ui.md`

## 2. 目录命名

- 采用小写字母、数字和连字符组合
- 使用技术栈或主题名称
- 目录名与 frontmatter `name` 必须一致

## 3. 版本标识

- 使用语义化版本号，格式：`major.minor.patch`
- 示例：`1.21.1`、`1.20.1`

## 4. 标签命名

- 主标签使用简洁的分类名称，从提交规则中的标签体系选取（1-3 个）
- 二级标签可包含技术栈、版本号、功能关键词
- 示例：`我的世界开发`、`特定模组开发`、`neoforge`、`1.21.1`

## 5. 命名原则

- 唯一性：避免名称冲突
- 一致性：保持命名风格统一
- 可搜索性：使用易于搜索的关键词
- 可扩展性：预留未来扩展空间
